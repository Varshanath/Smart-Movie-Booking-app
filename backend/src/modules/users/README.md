# Users Module

The users module owns profile data collected during registration and onboarding.

## User Fields

- `id`: unique user identifier
- `name`: user's full name
- `gender`: `male`, `female`, `other`, or `prefer_not_to_say`
- `location`: user's city or preferred booking location
- `moviePreference`: list of preferred genres or movie categories
- `email`: unique email address
- `phoneNumber`: unique phone number
- `createdAt`: record creation timestamp
- `updatedAt`: record update timestamp
